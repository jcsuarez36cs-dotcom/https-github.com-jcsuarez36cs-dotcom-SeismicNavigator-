SeismicNavigator - How to Run Locally
======================================

STEP 1: Open a terminal (CMD, PowerShell, or Terminal) and navigate into the project folder.

    cd SeismicNavigator


STEP 2: Create a virtual environment.

    python -m venv .venv


STEP 3: Activate the virtual environment.

    Windows CMD:
        .venv\Scripts\activate

    Windows PowerShell:
        .venv\Scripts\Activate.ps1

    Mac / Linux:
        source .venv/bin/activate

    You should see (.venv) at the start of your terminal prompt when it is active.


STEP 4: Install the required packages.

    pip install -r requirements.txt


STEP 5: Start the app.

    uvicorn app.main:app --host 0.0.0.0 --port 8000


STEP 6: Open your browser and go to:

    http://127.0.0.1:8000


======================================
NOTES:
- You only need to do Steps 1-4 once (or after updating requirements.txt).
- To stop the server, press Ctrl+C in the terminal.
- Every time you open a new terminal you will need to repeat Step 3 (activate) before Step 5.
